# Changelog

## 2.0.0 — 2026-10-17

### Added
- 8 languages: Arabic, English, Spanish, French, German, Italian, Portuguese and Turkish, with automatic detection, right-to-left layout for Arabic and localized numbers, currencies, dates and CSV headers.
- Six-month income vs. expenses chart; click a month to open it.
- Edit transactions, delete with undo, search and filter by type or category.
- Light / dark / system theme.
- Installable app (PWA) that works offline.
- Sample data to try the app in one click.
- 24 currencies, with names shown in the selected language.
- Landing page listing all solutions, GitHub Pages deployment, CI.

### Changed
- Categories are stored as language-independent ids. Data from version 1 is migrated automatically on first load.

## 1.0.0

- First release: Arabic expense tracker with monthly summary, category breakdown, saving tips, subscriptions, budget, CSV export and JSON backup.
